# 缠论RAG 0.4.2｜本地AI安装指南版

## 下载并交给AI连接

下载附件 **chanlun-rag-0.4.2-windows-x64.zip**，右键选择“全部解压”。将解压文件夹中的 **INSTALL_FOR_AGENT.md** 拖给你使用的AI客户端，再复制同目录 **AI安装提示词.txt** 的内容发送。

指南和所需运行组件均已包含在压缩包中。AI读取本地指南，不需要联网查安装文档。Codex、Claude Desktop、WorkBuddy等等只是客户端示例。

## 本版更新

- 本地安装指南、安装提示词、手动备查教程和README封面随运行ZIP提供。
- 问题示例增加理解联系、逻辑推导、关系界定、细节难点及带截图的实际案例分析。
- 指导Agent先验证本地包，再安全合并连接，并实际查一次原文。

检索核心、知识、模型和索引沿用已经验证的固定版本。各客户端逐一登录的完整界面验收、全新Windows系统验收仍未完成；本版不将这些项目改写为通过。

附件中的 `.zip.sha256` 可用于核对完整下载件。专业手动配置步骤保留在包内“开始使用.md”的末尾。
