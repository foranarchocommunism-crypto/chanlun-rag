# Windows x64 兼容与验证

本次交付面向 **Windows 10 1809 及以后版本、Windows 11 的 x64 系统**。包内提供固定 Node 24.15.0、ONNX、sharp、对应的本地 C++ 运行库、CPU 模型、索引和知识库。日常使用无需管理员权限、Docker、Python、全局 Node 或开发软件。

2026-10-23，用户明确决定停止下载、直接交付 x64，并清除本轮安装下载的虚拟机、容器和临时环境。此决定取代此前双架构和容器验收范围。ARM64、32 位及 Windows 7/8/8.1 不在本次交付范围内；没有把未完成的 ARM64 或容器验收记为通过。

解压后在 PowerShell 运行：

```powershell
.\doctor.cmd -Full
.\verify.cmd
.\chan-kg.cmd status
```

doctor 检查架构、Windows 版本、包内运行时和隔离 PATH 查询；`-Full` 执行实际向量和重排。verify 检查全部文件、三种模式、CLI/JS/真实 MCP stdio 一致性和实际加载的包内运行库。启动器拒绝包内未提供的架构。建议至少 8 GiB 内存和 3 GiB 空闲磁盘；首次加载模型可能较慢。

0.4.0 实际运行证据来自当前 Windows x64 主机、包内运行时、隔离 PATH、关闭 Node 网络调用，以及全新 ZIP 解压件。历史 0.3.0 的独立 Windows Server 2022 普通用户断网验收不能替代本版本验收。Windows 11 x64 是兼容目标，没有逐个 Windows 构建和物理设备的实测保证。准确的 ZIP 哈希及环境结果以正式交付回执为准。

检索代码、模型、知识和选定参数沿用冻结评测。环境配置、软件卸载和临时数据清除结果保存在维护工程的清理回执中；便携包使用者无需安装验收环境。
