# 固定知识库的使用与恢复

知识库已经冻结，后续不接收新知识，不需要运行导入、增量更新或在线维护任务。

日常使用直接运行 chan-kg.cmd 或 chan-kg-mcp.cmd。文件完整性检查运行 verify.cmd；环境诊断运行 doctor.cmd -Full。

如果文件损坏或校验失败，关闭使用本目录的 Agent 服务，从正式 ZIP 解压一套新目录，运行 verify.cmd 后重新连接。保留故障目录用于核查。不要拼接不同发布包里的数据库、索引、模型或配置。

源码构建工具是复现与修复工具。build-index.mjs 只在独立构建目录生成派生索引；build-vectors.mjs 支持通过哈希验证的检查点恢复。构建工具不修改正式知识库，不自动切换正在使用的发布目录。

每个正式发布都应保存源码提交、文件清单、ZIP 哈希及全新解压件的运行回执。机器校验能证明文件一致、引用匹配和状态隔离，不能替代缠论内容的语义判断。
